# Glossary

| Term | Meaning |
| --- | --- |
| Know your customer (KYC) | Identifying and verifying a customer and understanding their risk |
| Know your business (KYB) | The same for a legal entity: ownership, control, activity |
| Customer due diligence (CDD) | The standard level of customer checks |
| Simplified due diligence (SDD) | Reduced checks for demonstrably low risk |
| Enhanced due diligence (EDD) | Deeper checks for high risk, with senior approval |
| Background check | A set of checks on one person for a specific decision |
| Beneficial owner (UBO) | The individual who ultimately owns or controls an entity |
| Politically exposed person (PEP) | A person with a prominent public function |
| Relatives and close associates (RCA) | Family members and close contacts of a PEP |
| Source of wealth (SoW) | How a person's overall wealth was generated |
| Source of funds (SoF) | Where the specific funds in a relationship came from |
| Adverse media | Negative publications about a person or entity |
| Screening | Checking names against sanctions, PEP and other lists |
| False positive | A match that turns out not to be the subject |
| Tipping off | Warning the subject of a suspicion (prohibited) |
| Liveness detection | A check that a live person is present during biometric verification |
| Presentation attack | An attempt to fool biometric verification with a fake |
| Synthetic identity | An identity built from a mix of real and fabricated data |
| Sanctions evasion | Circumventing sanctions through intermediaries, successors, transit |
| Secondary sanctions | Measures against third parties that deal with sanctioned persons |
| General license | A licence authorising certain dealings, for example winding down |
| Designation | Adding a person or entity to a sanctions list |
| Delisting | Removing a person or entity from a sanctions list |
| Shadow fleet | Vessels used to move sanctioned goods with opaque ownership |
| Shell company | An entity with no real activity |
| Nominee director or shareholder | A person recorded in a register in place of the real owner |
| Corporate trustee | A professional trust agent holding assets for a client |
| Effective ownership | A person's share in a company calculated through a chain |
| Effective control | The ability to determine an entity's decisions |
| Related party | A person or entity linked by ownership, management or family |
| Legal Entity Identifier (LEI) | A 20-character global identifier of a legal entity |
| IMO number | A permanent vessel identification number |
| Grey list (FATF) | Jurisdictions under increased monitoring |
| Black list (FATF) | Jurisdictions subject to a call for action |
| Primary source | An original document or register entry |
| Chain of custody | The documented path of evidence from collection to use |
| Confidence level | How reliable a conclusion is, on an agreed scale |
| Cutoff date | The date after which information is not used in a retrospective review |
| Analysis of competing hypotheses (ACH) | Weighing versions by the evidence that refutes them |
| Hash | A digital fingerprint of a file used to prove it is unchanged |
