## Sanctions: European Union (S)

- **20th package (23 April 2026):** the first anti-circumvention tool used against a third country (Kyrgyzstan), 46 vessels added and 11 removed, a ban on RUBx and the digital rouble, a ban on dealings with Russian crypto-asset providers.
- **21st package (23 July 2026):** 218 listings (48 individuals and 170 entities), including the Moscow Exchange.
- **22nd package (12 October 2026):** 1,569 listings (743 individuals and 826 entities), more than half tied to the ballistic missile production chain; the largest expansion of the lists since 2022.

## OpenSanctions changes affecting integrations (S)

From 28 January the gb\_hmt\_sanctions dataset stopped receiving new records, use gb\_fcdo\_sanctions instead; the second API (KYB and Graph) was switched off on 31 December 2025; the features and matcher fields in `/match` responses were replaced by explanations (migration finished on 2 March 2026); compatibility for the weakAlias field ends in September 2026.

The lesson: read the changelog before updating scripts and state the dataset version in the report.
